# Vero — site institucional

Site de uma página da Vero, agência de gestão de tráfego, automação de CRM e lojas
virtuais para marcas de moda e e-commerce.

## Seções

1. **Hero** — paisagem em tela cheia, título, subtítulo e chamadas para ação.
2. **Serviços** — três cards que se empilham conforme a página rola.
3. **Resultados** — números principais sobre arcos com indicadores de campanha.
4. **Trabalhos** — carrossel em arco com as capas dos sites entregues.
5. **Footer** — chamada final, links e contatos.

## Estrutura

```
index.html     marcação de todas as seções
styles.css     estilos e tokens de cor/tipografia
script.js      comportamentos (cards empilhados, carrossel, menu, brilhos)
assets/        imagem de fundo da hero
```

Não há build: basta abrir o `index.html` ou servir a pasta.

## Pendências

- Substituir os números da seção de resultados pelos valores reais.
- Trocar os mocks do carrossel pelas capturas dos sites entregues.
- Preencher e-mail, telefone, cidade e links das redes no rodapé.
